# 相机与记录适配层

- `CameraService`：主线程可观察状态，专用串行队列发现和配置后置广角、超广角与长焦；按可用硬件提供镜头入口。不采集音频。
- `captureReading`：最多等待约 2 秒；接受目标偏移绝对值小于 0.3 EV、自动曝光结束、至少 4 个连续近似稳定样本（相邻差小于 0.15 EV），且最新样本小于 0.5 秒的帧。等待可取消。
- 曝光优先取视频帧 EXIF 附件；设备未提供附件时，读取同次帧回调中的设备曝光参数。后者不是硬件原子配对，稳定门槛只能降低时间差影响，需真机和灰卡验证。
- EV100 = 光圈/时间/ISO 曝光基准 + 空间亮度修正 + 用户校准。不把 `exposureTargetOffset` 的未验证符号带入公式；设备中心兴趣点只服务于自动曝光，矩阵/中央重点/点测由应用内 `SpatialMetering` 独立计算。
- 同一冻结帧按可见宽高比中心裁切，`LuminanceSampler.grid` 将 BGRA 可见区域划为 48×64 等面积区域并求线性亮度均值；每个可见像素参与，边界像素按覆盖面积加权，行填充与裁切外像素不参与。256 项通道查找表用于线性化，矩阵等权汇总区域均值，中央重点叠加高斯权重，点测圆直径为可见短边 16%。输出参考图使用同一可见裁切；计算仅发生在 capture 请求，不在每帧回调中执行。处理过的视频颜色并非 RAW，精度与计算耗时仍须真机验证。
- 视频帧为竖屏 720p 参考图；实时取景使用 `resizeAspectFill`。镜头切换实际更换 `AVCaptureDeviceInput`；支持时提供标明的 2× 数码裁切，不把裁切称为光学镜头。iOS 26 使用设备有效标称焦距，旧系统按视场角估算相对倍率。它不是高分辨率拍照功能。
- 切镜头时清除旧样本，失败回滚原输入；目标倍率不支持时返回错误而非静默钳制。生命周期版本和帧时间共同过滤过期结果。
- `stop` 用于页面离开/后台；上层在回到前台后按已授权状态调用 `start`。启动前后核验系统 `AVCaptureSession.isInterrupted`，恢复、切镜头及采样路径拒绝尚未解除的中断，不能仅凭内部标记或 `startRunning` 返回认定中断结束。中断、媒体服务重置和失败发布可显示状态，上层使旧测光基准失效；实际系统中断与恢复仍待真机验收。
- `TrendRenderer` 只对冻结参考帧做 −3 至 +3 EV 的亮暗趋势展示；不能预测胶片、局部剪裁或场景动态范围。
- `RecordExporter.compose` 使用原始参考帧生成带边框和文字的记录图，仍由主 Actor 同步调用，未完成硬件性能测量；`save` 仅请求 Photos `.addOnly`，添加到最近项目，不枚举照片或创建命名相册。记录页固定操作栏只改变交互布局，不改变合成执行方式。
- `ShareSheet` 提供系统分享作为导出路径。授权拒绝和保存失败不会销毁传入的待保存图片。

此前第三轮通过了 iOS 17 最低目标、iOS 26.5 SDK 的设备目标无签名构建。本轮新增区域均值采样与系统中断核验，最新构建/执行结果以[开发验证记录](../../Docs/04-开发验证记录.md)为准；旧构建成功不能替代新改动验证。真实镜头切换、空间测光精度、稳定门槛、照片权限及生命周期仍需真机验收。
