暗房测光台：取景是主角，读数像仪表

主界面固定深色，取景全宽贴边；玻璃控件只浮在画面上。光圈与快门放大成仪表读数，用刻度拨盘调节，主测光按钮做成快门。强调色从系统蓝换成琥珀色。

现在哪里不好看

  • 像设置页：浅灰底、白卡片、系统蓝，看不出是相机工具。
  • 没有主次：取景、分段控件、参数卡、按钮四块等权堆叠。
  • 玻璃发灰：Liquid Glass 放在浅底上，看不出折射。
  • 文字太多：“曝光趋势”“演示广角”“你选光圈，光格算快门”“1/3 档”常驻。
  • 操作不像相机：通用 Slider 加减号，主按钮是蓝色胶囊，返回实时的按钮悬在画面中间。

琥珀色只用于三种情况：选中的参数、锁定状态、测光取样点。拨盘每跨 1/3 档给一次 selection 触感，锁定成功给 success，失败给 warning。
