# 07 · 分区曝光视图（Zone View）

> 执行规格。目标：按亚当斯分区曝光法，把画面每个区域在**当前曝光参数**下落在第几区显示出来，并叠加所选胶片的宽容度窗口。视觉沿用 [06 · UI 视觉与交互重设计](06-UI视觉与交互重设计.md) 的暗房测光台风格。
>
> 分三期交付。**本轮只做第一期（MVP）**，第二、三期仅作规划，不实现。

## 1. 定位与原则

- **可选视图，默认关闭**。不改变"测光 → 调参 → 记录"主流程；关闭时界面与现在完全一致。
- **诚实标注精度**。数据来自手机处理后的 8 位视频帧，不是专业测光表；两端用 `≤I` / `≥VIII` 表示，不硬给精确区号。
- **只多一个入口**。取景浮层增加一个"分区"开关；其余信息复用现有仪表区位置。
- 不新增第三方依赖、不联网、不改变隐私策略。

## 2. 概念与公式

### 2.1 分区定义

| 区 | 0 | I | II | III | IV | V | VI | VII | VIII | IX | X |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 含义 | 纯黑 | 近黑无质感 | 最暗有质感 | 暗部细节 | 暗中间调 | 18% 中灰 | 亮中间调 | 亮部细节 | 最亮有质感 | 近白无质感 | 纯白 |

每区相差 1 EV。区 V = 当前参数把该亮度曝光成中灰。

### 2.2 每格场景亮度（复用现有测光数据）

现有 `CameraService.captureIfStable` 已在可见裁切内计算 48×64 格线性亮度 `Y`（`LuminanceSampler.grid`），读数为：

```
reading.ev100 = sample.ev100 + SpatialMetering.correction(...) + calibrationEV
correction    = log2(加权平均Y / 0.18)
```

因此每一格的场景 EV100：

```
frameEV100 = sample.ev100 + calibrationEV          // 设备本帧曝光 + 校准，不含测光加权
cellEV100  = frameEV100 + log2(max(Y_cell, 1e-6) / 0.18)
```

### 2.3 区号

```
zone_cell = 5 + ExposureEngine.deltaEV(ev100: cellEV100, setting: model.setting)
```

`deltaEV` 已定义为"场景 EV100 − 参数 EV100"，正值表示该区域相对当前参数更亮。补偿已体现在 `setting` 中（A/S 求解后），**不要再额外加补偿**。验证：矩阵测光、补偿 0 时，全画面加权平均亮度对应区 V；补偿 +1 时对应区 VI。

### 2.4 裁剪/饱和处理

| 条件 | 显示 |
|---|---|
| 该格 ≥ 2% 像素的任一通道 = 255（需在采样时统计） | `≥` 当前计算区号，且不低于 VIII 时记为 `≥VIII` |
| 该格线性亮度 < 0.002 | `≤I` |
| 其余 | 四舍五入到整数区，内部保留 Double |

MVP 可先用格平均值近似：`Y_cell ≥ 0.95` 视为饱和，`Y_cell ≤ 0.002` 视为欠采样；饱和像素占比统计放第二期。

## 3. 胶片宽容度模型

新增 `FilmLatitude`（LumaCore），以 `FilmKind` 提供**教学典型值**：

| FilmKind | 有质感区间 `textured` | 细节边缘 `detail` | 备注 |
|---|---|---|---|
| `.slide` 反转片 | III…VII | II…VIII | 窗口最窄，偏向保高光 |
| `.negative` 彩色负片 | III…IX | II…X | 过曝宽容，欠曝敏感 |
| `.blackAndWhite` 黑白负片 | II…VIII | I…IX | 第二期增加 N−1/N/N+1 显影修正（高光窗口 ∓1） |

每格分类：

```swift
enum ZoneClass { case blocked      // < detail.lower   暗部死黑
                 case shadowEdge   // detail.lower ..< textured.lower
                 case textured     // textured 区间内
                 case highlightEdge// textured.upper ..< detail.upper
                 case clipped }    // > detail.upper   高光溢出
```

文案与无障碍统一称"典型宽容度"，说明页注明"随具体胶卷、显影与扫描变化"。现有 `ExposureEngine.risk` 保持不变，后续可改为基于 `FilmLatitude` 实现，但本轮不改其行为。

## 4. 交互与界面

### 4.1 入口

- 取景下缘左侧测光方式胶囊旁，新增玻璃小胶囊 `▥ 分区`（`square.grid.3x3.middle.filled` 或类似 SF Symbol）。开启时琥珀描边，再点关闭。
- 状态持久化到 `UserDefaults`（键 `zoneView`），默认 `false`。
- `accessibilityIdentifier("zoneToggle")`，标签"分区视图，已开启/已关闭"。

### 4.2 未测光（实时取景）

MVP **不做实时叠加**（第二期）。开启分区后，未测光时取景画面下缘显示一行提示 `测光后显示分区`（`.caption`，与 DEMO 同风格的描边徽标），不遮挡画面主体。

### 4.3 锁定读数后（MVP 核心）

1. **分区灰阶图**：在冻结参考帧上渲染 11 级灰阶（区 0→X 对应灰度 0%→100%，按区线性分布），替代当前趋势图显示。
   - 实现：`ZoneRenderer`（App/Services），用 `CIColorCube` 或 `CIColorKernel`：像素 → 线性亮度 → `cellEV` 同一公式逐像素计算区号 → 量化到 11 级灰。参数变化只改偏移量，重建 LUT 即可。
   - 与 `TrendRenderer` 一样：后台队列、一次只渲染一张、只保留最新请求。
2. **宽容度外标注**：`blocked` 区域叠蓝色 45° 斜线（`Color.blue.opacity(0.55)`），`clipped` 区域叠琥珀/红色斜线（`LF.critical.opacity(0.6)`）。`shadowEdge` / `highlightEdge` 不画斜线，仅在分区尺上体现。斜线基于 48×64 格绘制即可（`Canvas`），对齐取景可见区域。
3. **读区号**：分区视图开启时，**长按**画面任一点 0.3s 弹出气泡 `VI · +1 EV · 有质感`（区号 + 相对区 V 的档数 + 分类）。点测光模式下的点按移动测光点保持不变。气泡 2s 后淡出；VoiceOver 下改为"读取区号"自定义操作，朗读测光点所在格。
4. **拨盘联动**：转动光圈/快门/补偿拨盘时，灰阶图、斜线、分区尺随 `setting` 实时更新（只改偏移，不重新采样）。
5. 关闭分区后恢复原趋势图显示。

### 4.4 分区尺（替换偏移刻度）

分区开启且已测光时，仪表区顶部状态行的"−3…+3 偏移刻度"替换为分区尺：

```
EV 12.0   0  I  II III IV  V VI VII VIII IX  X
          ▁  ▂  ▅  ▇  █  ▆  ▃  ▂  ▁   ·  ·     ← 画面面积直方图（每区一柱）
             [════════ 典型宽容度 ════════]     ← 胶片 textured 区间，琥珀色细框
                         ▲                     ← 测光区域所在区（琥珀指针）
```

- 11 列等宽；柱高 = 该区格数 / 总格数，最大 14pt。
- 宽容度外柱子着色：暗端蓝、亮端红；区间内柱子 `LF.inkSecondary`。
- 右侧追加一行短语（≤8 字）：`3% 高光溢出` / `暗部 12% 死黑` / `全部在宽容度内`，取占比较大者。
- 未测光或分区关闭时恢复原偏移刻度。SE 与辅助字号：区号标签只显示 0、III、V、VII、X；辅助字号下柱子高度不随字号放大。
- `accessibilityIdentifier("zoneScale")`；朗读示例"分区分布：区 V 占 31%，高光溢出 3%，典型宽容度 III 到 IX"。

### 4.5 记录

- `RecordDraft` 新增不可变 `zoneSummary`（各区占比 + 胶片宽容度 + 溢出/死黑占比），记录时冻结。
- 相纸卡片参数下新增一行迷你分区尺（与 4.4 同样式的浅色版），参数两列中新增 `分区` 行，例如 `高光溢出 3% · 暗部 0%`。
- 导出图仍为**未加分区处理的参考图**；分区灰阶图不导出（第二期再考虑"另存分区图"）。

### 4.6 演示模式

- `DemoScene` 预览需能产出 48×64 亮度格：把 `demoPreview` 渲染为 BGRA 后调用 `LuminanceSampler.grid`，`frameEV100` 取 `demoEV + calibration − 加权correction` 使矩阵读数与现有演示一致。
- 分区尺与气泡末尾加 `演示`，不得让演示数据看起来像实测。

## 6. 测试与验收

### 6.1 LumaCore 单测（全部为合成数据）

1. 均匀 0.18 灰场、矩阵测光、设置等于建议值 → 所有格区 V。
2. 同场景光圈缩小 1 档 → 所有格区 IV；补偿 +1 后求解 → 区 VI。
3. 左半 0.18、右半 0.72（+2EV）→ 两组格分别为 V 与 VII，直方图各 50%。
4. `FilmLatitude`：反转片区 VIII → `highlightEdge`，区 IX → `clipped`；负片区 IX → `textured`；黑白区 I → `shadowEdge`。
5. 饱和近似：`Y = 0.97` 标记 `≥`；`Y = 0.001` 标记 `≤I`；`Y = 0` 不产生 NaN/Inf。
6. 直方图占比之和 = 1（容差 1e-9）；空数组/尺寸不匹配返回 nil。
7. 测光区区号：点测光在亮区时指针落在该区。

### 6.2 UI 测试（双机）

1. `zoneToggle` 默认关闭；开启 → 测光后 `zoneScale` 存在且原偏移刻度不存在；关闭 → 恢复。
2. 分区开启时转动光圈拨盘一格，`zoneScale` 的 accessibilityValue 变化。
3. 长按画面出现区号气泡；点测光模式下点按仍移动测光点。
4. 记录 Sheet 中出现 `分区` 参数行；保存流程不变。
5. 重启 App 后分区开关状态保留。
6. SE 普通字号：分区开启 + 已测光时首屏无需滚动即可看到分区尺、HERO、拨盘、底栏。
