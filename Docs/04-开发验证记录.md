# LumaFrame 光格：开发验证记录

日期：2026-11-02 · 发布前验证基线

## 1. 验证结果

| 检查 | 结果 | 范围 |
|---|---|---|
| 完整 UI 回归 | **48/48 通过** | iPhone SE（第 3 代）与 iPhone 17 Pro 各 24 项；零失败、零跳过 |
| 核心测试 | **34 项 / 3 套件通过** | 曝光计算、空间测光与亮度采样 |
| 无签名 Release 构建 | **通过** | generic/platform=iOS，Release，CODE_SIGNING_ALLOWED=NO |
| 工具链 | Xcode 26.6（17F113） | 两台模拟器均使用 iOS 26.5 |

三个验证命令退出码均为 0。以上是开发环境执行的发布前记录，不是 GitHub CI 的运行状态。仓库发布准备仅清理环境相关说明、忽略规则和图片附加元数据，应用源码、测试与工程配置保持验证版本不变。

原始运行日志、模拟器标识、构建缓存及私有环境配置不纳入仓库。可按 [README](../README.md) 的命令重新验证，并把设备名替换为当前可用模拟器。构建目录使用项目内已忽略的 .build/，不依赖外部工作区布局。

## 2. 覆盖范围

- 测光、记录预览、相册保存、保存失败重试与权限拒绝入口。
- A / M / S 模式、自动参数只读、补偿、参数拨盘拖动与吸附。
- 镜头及测光方式切换、点测拖动、锁定状态与返回实时。
- M 模式首屏的偏移刻度、HERO、拨盘、胶囊和底栏可达性。
- accessibility3 下补偿胶囊完整滚入视口并点击，accessibility5 下参数和记录可读。
- 胶卷与 ISO、弹层外观、降低透明度和减少动态效果分支。

相关修复包括：偏移刻度固定于滚动区外；M 模式建议参数并入胶囊行；辅助字号记录按标签在上、值在下排列；相纸参数和导出图使用同一份结构化两列排版；AE-L 改为被动描边徽标；胶卷半屏使用不透明系统背景。

故障和辅助功能分支使用受 -ui-testing 限制的测试参数；它们不代替真实系统故障和辅助功能开关验收。

## 4. 尚未覆盖

- 真实镜头、相机中断、测光精度、功耗及完整 VoiceOver 仍需实体 iPhone 验证。
- iOS 17–25 的运行效果与材质回退尚未完成逐版本实测。
- 分享按钮与保存流程通过，不代表所有外部分享目的地均已验证。
- 系统滚动条在滚动时出现；辅助字号截图不代表默认字号密度。
- 本记录不代表签名安装、TestFlight 或 App Store 发布验收。
