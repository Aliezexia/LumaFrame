# 06 · UI 视觉与交互重设计（暗房测光台）

> 本文是下一轮 UI 改造的执行规格。只改表现层与交互，不改 LumaCore 算法、曝光计算、记录/导出逻辑和隐私策略。

## 1. 现状问题（基于 Previews/iPhone17Pro 01、09、17 截图）

| # | 问题 | 结果 |
|---|---|---|
| P1 | 浅灰 `systemGroupedBackground` + 系统蓝 + 白卡片，像"设置页里放了张图" | 不像相机/测光工具，没有辨识度 |
| P2 | 取景框、分段控件、参数卡、按钮四块等权堆叠 | 视觉没有主次，最重要的"光圈/快门结果"不突出 |
| P3 | Liquid Glass 放在浅色底上发灰发脏 | 玻璃只有叠在画面上才好看 |
| P4 | 文案过多：读数已锁定/演示场景/曝光趋势/演示广角/你选光圈，光格算快门/1/3 档 | 噪音大，取景被文字切碎 |
| P5 | 参数调节用通用 Slider + −/+ | 缺少"拨盘"的手感，与胶片相机心智不符 |
| P6 | "重新测光"大蓝胶囊 + "记录"并列 | 主操作不像快门，"返回实时"按钮悬在画面中右侧，含义不清 |
| P7 | "M 手动 / A 光圈优先 / S 快门优先"整行分段 | 占一整行，但切换频率很低 |

## 2. 设计方向

**暗房测光台**：主界面固定深色（像系统相机），取景框是唯一主角；画面上方与下缘浮动玻璃控件；画面下方是黑底"仪表区"，用超大数字显示光圈与快门，下面是一条可拖动的刻度拨盘；最底部是相机式三按钮行。

强调色从系统蓝改为**琥珀色**（光、测光表指针、系统相机的激活黄），只用于"当前被选中/被锁定/取样点"。

## 3. Design Tokens（新建 `App/DesignSystem.swift`）

```swift
enum LF {
    // 颜色
    static let canvas      = Color.black                         // 主界面底色
    static let surface     = Color(white: 0.11)                  // 无玻璃回退 / 降低透明度
    static let ink         = Color.white
    static let inkSecondary = Color.white.opacity(0.62)
    static let inkTertiary = Color.white.opacity(0.36)
    static let hairline    = Color.white.opacity(0.12)
    static let amber       = Color(red: 1.00, green: 0.76, blue: 0.24) // #FFC23D
    static let warning     = Color.orange                        // 曝光风险
    static let critical    = Color.red                           // 严重风险
    // 字体
    static func hero(_ size: CGFloat = 52) -> Font { .system(size: size, weight: .semibold, design: .rounded) }
    static let label   = Font.footnote.weight(.medium)
    static let chip    = Font.subheadline.weight(.semibold)
    static let mono    = Font.caption.monospaced()
    // 尺寸
    static let gutter: CGFloat = 16
    static let chipHeight: CGFloat = 36       // 触控区仍需 ≥44，用 contentShape 扩展
    static let shutter: CGFloat = 76          // 主测光按钮外径
}
```

- 所有数字 `.monospacedDigit()` + `.contentTransition(.numericText())`（减少动态效果时关闭动画）。
- 删除 `MeterTheme` 中的 `systemGroupedBackground`/`.blue`，全局 `.tint(LF.amber)`。
- 主界面 `.preferredColorScheme(.dark)` 固定；设置里的"外观"选项仅作用于 Sheet（记录、设置、胶卷）。

## 4. 主界面布局（iPhone 17 Pro 402×874pt 为基准）

```
┌────────────────────────────────┐
│ [◎ 负片 · 400]         [⚙]    │ 玻璃胶囊，浮在画面上（状态栏下 8pt）
│                                │
│          取景画面 3:4           │ 宽度贴边（0 gutter），顶部延伸到状态栏后
│        （点测光：琥珀圆环）       │
│                                │
│ [▦ 矩阵 ▾]      [DEMO] [🔒 AE-L]│ 画面下缘 12pt：测光方式 / 演示 / 锁定
│          ( .5  1×  2 )          │ 镜头胶囊，系统相机样式
├────────────────────────────────┤ 黑底仪表区
│  EV 12.0   −3 ·· ·|· ·· +3      │ 状态行 + 曝光偏移刻度（指针琥珀色）
│                                │
│   f/5.6            1/500        │ HERO：52pt rounded，两列
│   光圈              快门 · 自动   │ 选中列数字琥珀色，自动列为 inkSecondary
│                                │
│  ┆ ┆ ┆ ╎ ┆ ┆ ┃ ┆ ┆ ╎ ┆ ┆ ┆      │ 刻度拨盘（1/3 档一格，整档标数字）
│   4     5.6     8     11        │
│                                │
│  [A 光圈优先 ▾]  [±0.0 EV]       │ 两个次级玻璃胶囊
│                                │
│  [记录缩略图]   ( ◉ 测光 )   [↺]   │ 相机式底栏
└────────────────────────────────┘
```

### 4.1 取景区
- 取景框 **全宽、无圆角**，`ignoresSafeArea(edges: .top)`，比例 3:4。高度 = `min(width × 4/3, 可用高度 − 仪表区最小高度)`；SE（375×667）仪表区最小约 300pt，取景会自动变扁，`updateViewfinderAspect` 继续保证记录裁切一致。
- 删除顶部/底部黑色渐变遮罩上的说明文字，只保留轻量渐变（顶部 0.35、底部 0.45 黑）保证玻璃控件对比。
- **锁定态**：画面四周 2pt 琥珀描边 + 右下 `AE-L` 锁定胶囊（`lock.fill`）。点胶囊 = 返回实时（替代原悬在画面中右侧的 `arrow.uturn.backward` 按钮）。
- **点测光**：琥珀色细圆环（1.5pt）+ 中心点；支持**点按和拖动**移动；出现时 0.9→1.0 缩放 + `sensoryFeedback(.selection)`。中央重点保持白色虚线圆。
- **镜头胶囊**：样式参考系统相机，选中项为琥珀字 + 小圆底，未选中白字；镜头说明（"演示广角"等）不常驻，切换后在胶囊上方以小 toast 显示 1.5s 再淡出。
- **演示**：只显示一个 `DEMO` 小胶囊（`.caption2.weight(.bold)`，琥珀描边），VoiceOver 仍朗读"演示场景，非实测"。
- 未授权相机：整块取景区为 `LF.surface`，居中 `camera.aperture` 图标 + 标题 + 琥珀实心"启用相机" + 文本按钮"先体验演示"。

### 4.2 仪表区
- **状态行**：左 `EV 12.0`（mono，inkSecondary）；右侧"曝光偏移刻度"——−3…+3，每 1/3 档一个小刻度，0 处长刻度，指针为琥珀三角。M 模式显示 `delta`，A/S 显示补偿后偏移。存在风险时刻度右侧加 `warning`/`critical` 色圆点 + 3–6 字短语（如"高光易溢出"），点按弹出 popover 详细说明。未测光时整行显示 `对准主体，按下测光`。
- **HERO 读数**：光圈、快门两列等宽；数字 52pt（SE 44pt，辅助字号改为纵向列表）；下方标签 `LF.label`。
  - 可调列：数字白色，被选中时数字琥珀色 + 标签下 2pt 琥珀短线。
  - 自动列：数字 inkSecondary，标签后加 `自动`。点自动列不切换，只给一次 `.sensoryFeedback(.impact(weight: .light))`。
  - 未测光时自动列显示 `—`。
  - ISO 不再占 HERO 位，放在左上胶卷胶囊（`负片 · 400`）。
- **刻度拨盘**（新建 `App/StopDial.swift`，替换 Slider + −/+）：
  - 横向 `ScrollView` + `.scrollTargetBehavior(.viewAligned)` + `.scrollPosition(id:)`；每 1/3 档一个刻度（间距 14pt），整档刻度更长并标数值；中线琥珀色固定指针；两侧 24pt 渐隐遮罩。
  - 每跨一格 `.sensoryFeedback(.selection, trigger: index)`。
  - 编辑对象 = 当前选中参数（光圈 / 快门 / 补偿）；自动参数时拨盘半透明并显示"自动计算"。
  - 无障碍：`.accessibilityElement()` + `.accessibilityValue(...)` + `.accessibilityAdjustableAction` 上下滑调 1/3 档；保留 `decreaseParameter` / `increaseParameter` 等价入口（可做成拨盘两端的小 chevron 按钮，或改 UI 测试走 adjustable）。
- **次级胶囊行**：
  - `A 光圈优先 ▾`：Menu 选 M/A/S（替代整行分段控件）。
  - `±0.0 EV`：点按 = 拨盘切到"补偿"；非零时琥珀描边；`contextMenu` 提供"归零"和"补偿说明"（原 `ExposureAdjustmentSheet` 作为说明页保留）。
  - M 模式已测光时，增加第三个胶囊 `采用建议 f/5.6 · 1/500`。
- 删除：常驻的"你选光圈，光格算快门""1/3 档""曝光趋势"文本；原 `exposureSummary` 卡片并入状态行。

### 4.3 底栏（相机式）
| 位置 | 控件 | 行为 |
|---|---|---|
| 左 | 52pt 圆角方形缩略图 | 显示锁定的参考帧；无读数时为空框 inkTertiary；点按 = `prepareRecord()`（原"记录"按钮） |
| 中 | 76pt 测光主按钮 | 外环 4pt 白、内实心白圆、黑色图标：未测光 `viewfinder`，锁定后 `arrow.clockwise`；测光中外环变琥珀并旋转 trim 动画；锁定成功 `.sensoryFeedback(.success)`，失败 `.warning` |
| 右 | 44pt 玻璃圆按钮 | 锁定时 = 返回实时（`arrow.uturn.backward`）；未锁定且点测光时 = 测光点位置菜单（`scope`） |

按钮下方不放文字；VoiceOver 标签沿用"测光/重新测光/记录/返回实时取景"。

## 5. Liquid Glass 使用规则

- 玻璃只给**浮在画面上的控件层**：胶卷胶囊、设置、测光方式、镜头胶囊、AE-L、DEMO、底栏右侧圆按钮、次级胶囊。读数和拨盘不加玻璃（黑底直接显示，保证可读）。
- iOS 26：相邻玻璃控件用 `GlassEffectContainer(spacing:)` 包起来；可点控件用 `.glassEffect(.regular.interactive(), in: .capsule)`；锁定/解锁时 AE-L 胶囊用 `glassEffectID` + `@Namespace` 做出现/消失形变。
- iOS 17–25：`.ultraThinMaterial` + `environment(\.colorScheme, .dark)`；降低透明度：`LF.surface` 实底。沿用并扩展 `LiquidGlass.swift`，不要每处手写 `#available`。

## 6. Sheet 统一

- 记录、设置、胶卷 Sheet：`.presentationDetents` 合理设置，`.presentationBackground` 用系统默认；tint 统一琥珀。
- 记录 Sheet：分享改为顶部工具栏 `ShareLink`（玻璃），底部只保留一个琥珀实心"保存到相册"；保存成功后按钮变为"继续取景"。记录卡片保留当前"相纸 + 等宽参数"样式，参数行改为两列对齐（标签 inkSecondary，值 mono）。
- 胶卷 Sheet：把胶卷类型做成三张带色块的选择卡（彩负 / 反转 / 黑白），ISO 用同一个 `StopDial` 组件（ISO 档位）。

## 7. 动效与触感

| 事件 | 动效 | 触感 |
|---|---|---|
| 测光中 | 主按钮外环琥珀 trim 旋转 | — |
| 锁定成功 | 琥珀描边淡入 0.2s，数字 numericText 滚动 | success |
| 测光失败/重测失败 | 主按钮轻微左右抖动 | warning |
| 拨盘跨档 | — | selection |
| 切换镜头/测光方式 | 胶囊选中块 matchedGeometry 滑动 | selection |
| 点测光移动 | 圆环弹性移动 | selection |

全部遵守 `accessibilityReduceMotion`（改为淡入淡出或无动画）。

## 8. 大字号与小屏

- `DynamicTypeSize.accessibility1+`：取景固定 260pt，仪表区可滚动，HERO 改纵向"标签 — 值"列表，胶囊行换行。
- SE：HERO 44pt，拨盘刻度间距 12pt，底栏主按钮 68pt；首屏需同时看到取景、HERO、拨盘、底栏。

## 9. 保持不变

- `LumaCore` 全部源码与测试；`MeterModel` 的公开行为（模式、测光方式、点测坐标、补偿、记录草稿、帧号、保存失败重试）。
- 现有 accessibilityIdentifier 尽量保留；确需改名时同步修改 UITests。
- 无第三方依赖、iOS 17 最低版本、离线、无账号。

## 10. 验收

1. 两种模拟器（iPhone 17 Pro、iPhone SE）完整 UI 回归全部通过，核心单测通过，无签名设备构建通过。
2. 重新生成 Previews 截图，至少包含：实时取景、锁定读数、点测光拖动、拨盘调光圈、M 模式采用建议、补偿非零、记录 Sheet、胶卷 Sheet、SE 首屏、大字号、降低透明度。
3. 自查清单：主界面没有系统蓝；画面上除 DEMO/AE-L/测光方式/镜头外无常驻文字；所有可点控件 ≥44pt 触控区；VoiceOver 能完成"测光→调光圈→记录→保存"。
4. 更新 README、02-产品与交互规格、04-开发验证记录中与界面相关的段落。

## 11. 视觉复核

对模拟器的实时、锁定、大字号与弹层截图逐项检查间距、数字基线、颜色对比、控件可达性和安全区遮挡。自动化断言通过不能替代截图检查；界面截图也不能证明真机性能或测光精度。后续设计调整以当前产品与交互规格和 Apple HIG 为依据。
