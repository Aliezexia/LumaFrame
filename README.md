# LumaFrame 光格

原生 iPhone 胶片测光与拍摄记录工具 · 重设计开发版 0.1 · 2026-11-02

LumaFrame 采用「取景 → 锁定读数与参考帧 → 调参 → 记录」的现场测光台流程，默认 A 光圈优先；M 模式不会被测光动作覆盖。

界面使用全宽取景、黑底仪表、琥珀强调色与刻度拨盘。普通字号的光圈/快门读数为小屏 36pt、常规屏 42pt，测光按钮为 64/68pt；胶囊视觉高度约 34pt，触区至少 44pt。iOS 26 的画面浮层使用系统 Liquid Glass，仪表区保持黑底。完整尺寸与行为见[产品与交互规格](Docs/02-产品与交互规格.md)。

取景以 3:4 为基准；宽度不足 390pt 或可用高度不足 740pt 时采用小屏布局，含底栏的仪表预留为 328pt，其余为 344pt。辅助字号另用 260pt 取景与可滚动仪表区，不代表普通字号密度。光圈、快门和补偿共用刻度拨盘；ISO 在独立胶卷弹层中调整。记录弹层顶部分享，底部只保留保存/重试/继续取景；外观可跟随系统或单独选浅色/深色，主测光界面始终深色。

可分别查看[普通字号主界面](Previews/iPhone17Pro/01-测光主界面.png)与[SE 辅助大字号布局](Previews/iPhoneSE/06-大字号参数.png)。验证结果与截图来源见[开发验证记录](Docs/04-开发验证记录.md)。

## 从这里开始

1. 用 Xcode 打开 `LumaFrame.xcodeproj`，选择共享 Scheme **LumaFrame**。
2. 选择已安装 iOS 运行时的 iPhone 模拟器，点击 Run。模拟器默认进入有明确标识的演示模式。
3. 从取景下缘选择矩阵、中央重点或点测光，再选择可用镜头/倍率。点测光支持点按、拖动圆心，或从菜单选择中心、上、下、左、右。移动取样点只清除旧读数，按下底部测光按钮才锁定新读数；AE-L 只表示锁定状态；锁定后点击右侧返回按钮恢复实时取景。
4. 点击光圈或快门读数选择可调项，拖动刻度拨盘或使用两端步进按钮。自动项只读，切换 M 后可分别调整两项。左上胶卷胶囊打开三种胶片选择卡与 ISO 拨盘；模式菜单切换 A/M/S，补偿胶囊切换到补偿拨盘，长按可归零或打开说明。切换镜头、测光方式、取样点或开始重测都会清除旧读数。
5. 点击左下记录缩略图检查相纸图与参数（辅助字号按标签在上、值在下排列），底部保存，顶部分享。较大曝光偏移时，点「查看曝光提醒」定位正文并自行确认；此按钮不会代为勾选。保存失败会定位错误原因并保留重试入口；成功后显示「继续取景」，旧读数已清除，须重新测光才能记录下一张，当前记录仍可分享。
6. 真机运行时，在 Signing & Capabilities 中选择自己的开发团队与可用 Bundle ID，再运行到 iPhone。首次由你点击「启用相机」后才请求权限。

要求：iOS 17+；构建需 Xcode 26 SDK。iOS 26 使用原生玻璃效果，iOS 17–25 回退为系统材质和标准按钮；降低透明度时使用实底。无第三方运行时依赖、无账号、无后端、无 API Key。仅支持 iPhone 竖屏；大字号内容可滚动。

在 Xcode → Settings → Locations 中选择对应的 Command Line Tools。未安装模拟器时，在 Xcode → Settings → Components 下载 iOS 运行时，并完成 Xcode 首次初始化。

## 本轮实现

| 能力 | 行为 |
|---|---|
| 现场测光 | 设备曝光稳定采样与可见区域亮度加权，2 秒有界等待，锁定同次参考帧 |
| 测光方式 | 矩阵等权网格、中央重点加权、可移动圆形点测光；与 A/M/S 曝光模式独立 |
| 镜头与倍率 | 按设备能力发现后置广角、超广角、长焦；支持时提供 2× 数码裁切，切换真实相机输入 |
| A / M / S | 自动项标记且只读；A/S 始终选中可调项；M 只在「采用建议」时应用推荐 |
| 三要素 | 光圈/快门为大号读数，使用吸附刻度拨盘；ISO 在胶卷弹层使用同一拨盘组件 |
| 曝光补偿 | 次级胶囊切换补偿拨盘；非零时琥珀描边，长按可归零或打开原生说明弹层 |
| 曝光趋势 | 固定参考帧的 ±3EV 滤镜演示；一次只生成一张趋势图，连续调参仅保留最新待处理请求 |
| 曝光提醒 | 负片、反转片、黑白负片的经验阈值；较大偏移在记录页确认 |
| 拍摄记录 | 未加趋势滤镜的参考图；常规两列、辅助字号上下排列，参数与草稿同步冻结，包含测光方式、镜头及点测位置；支持辅助字号与 VoiceOver |
| 导出 | 相纸参数按标签/值两列绘制，顶部原生 ShareLink 分享同一草稿 PNG，底部单一琥珀按钮保存/重试/继续；仅相册保存成功推进帧号，风险须手动确认 |
| 保存失败 | 保留草稿与帧号，支持重试或分享；仅权限拒绝提供系统设置入口 |
| 设置 | 胶卷独立入口；外观仅影响弹层，另含校准、九宫格、帧号、演示光线与权限入口 |
| 隐私 | 无联网、定位、麦克风、照片读取；权限按需申请 |

演示采用插画与预设曝光基准，1×/2× 仅作图像裁切，不能用来测量真实光线。真机 iOS 26 可显示设备提供的 35mm 标称焦距；旧系统按视场角估算相对倍率并标注“约”，不虚构 mm 数值。记录帧和空间测光使用同一可见裁切范围。BGRA 可见像素按 48×64 等面积区域计算线性亮度均值，矩阵测光对这些区域等权汇总；它不是厂商专有场景识别矩阵算法，不承诺专业测光精度。

## 工程结构

```text
App/                 SwiftUI、状态、设置、演示画面
  Services/          AVFoundation、Core Image、Photos、分享
  Assets.xcassets/   App 图标
LumaCore/            无 UI 依赖的曝光、空间加权、BGRA亮度采样与测试
UITests/             演示流程、M 模式、风险确认、设置与记录用例
Docs/                新版产品、交互、技术和验证文档
Tools/               无第三方依赖的 Xcode 工程生成器
```

App target 直接编译 `LumaCore/Sources` 中的同一份算法源文件；独立 Swift Package 使用这份源码运行测试，无重复算法副本。增加 Swift 文件后执行 `python3 Tools/generate_project.py` 更新工程，不需要 XcodeGen 或 CocoaPods。

## 验证命令

最近一次开发验证：双机 UI 48/48、核心 34 项 / 3 套件、iPhone 设备目标无签名 Release 构建全部通过。环境为 Xcode 26.6（17F113）、iOS 26.5 模拟器。此为发布前执行记录，并非 GitHub CI 状态；结果与覆盖范围见[开发验证记录](Docs/04-开发验证记录.md)。

在工程目录中执行，临时构建目录可以自行指定：

```sh
xcrun swift test --disable-xctest --package-path LumaCore \
  --scratch-path .build/core

xcrun xcodebuild -project LumaFrame.xcodeproj -scheme LumaFrame \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' \
  -derivedDataPath .build/ui test
```

第二条命令的设备名需替换成 `xcrun simctl list devices available` 中实际存在的 iPhone。测试使用 `-ui-testing` 启动参数隔离设置并启用演示，不读取真机相机。Swift Testing 用例需要 Swift 6 工具链。

错误恢复用例通过严格受 `-ui-testing` 限制的故障参数验证：`-ui-testing-fail-remeasure`、`-ui-testing-save-failure`、`-ui-testing-save-denied`。`-ui-testing-camera-placeholder` 用于检查首次相机引导布局。这些用例验证界面与状态恢复，不能代替真实设备的相机失败、系统授权拒绝或磁盘写入故障验收。

## 发布前仍需完成

测光准确性须在实体 iPhone、均匀灰卡和可靠参考测光表上验证。局部高光/暗部检测、具体胶片模拟、定位、连续测光、命名相册、历史库和商业化均未实现。开发版不能视为专业测光表、正式上架包或已经完成 TestFlight 验收的产品；签名、真机权限、功耗、完整无障碍与发布材料见验收文档。
